#### Ce que je construis

**🧠 EMNIST — Comparaison d'architectures**
Quatre réseaux confrontés sur 145 000 lettres manuscrites, 26 classes.
Exactitude portée de **83,6 % à 95,1 %** par optimisation Keras Tuner.
Le résultat qui compte n'est pas le score : c'est la démonstration que le MLP plafonne
pour une raison *structurelle*, et qu'aucun réglage ne rattrape une mauvaise architecture.

**📉 Moteur de KPIs sportifs — Données inertielles**
Un capteur, des entiers 16 bits bruités, 100 Hz. À l'arrivée : tirs, passes, sprints, distance.
Entre les deux, 13 modules — calibration automatique, filtrage Butterworth, fusion d'attitude
Madgwick, segmentation par analyse fréquentielle. **57/71 KPIs dans les tolérances**,
seuils réglés par Optuna, zéro magic number dans le code.

**🌍 Pipeline ETL climat & socio-économie**
Cinq sources qui n'ont jamais été conçues pour se parler — CO₂, qualité de l'air, démographie,
PIB, référentiel géographique — réconciliées en **1,1 million de lignes** exploitables.
Le vrai travail n'était pas la jointure. C'était de rendre chaque rejet traçable.

**🐾 WildLens — Classification d'empreintes animales**
Pipeline ML complet pour une association de préservation de la faune.
Données hétérogènes, terrain, conditions imparfaites.
